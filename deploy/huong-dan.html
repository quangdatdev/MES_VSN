Hướng dẫn chạy MES trên máy chủ

Mã nguồn ở D:\MES. Web chạy từ D:\MES-run. Mở PowerShell, chạy các lệnh dưới đây.

1. Cài đặt mớiLàm một lần, lần đầu chuyển sang cách chạy mới 2. Có code mới (git pull)Làm mỗi lần cập nhật

1. Cài đặt mới

Làm một lần. Nên làm ngoài giờ: web sẽ dừng khoảng 1 phút.

  1. Sao lưu 5 database MES_Core, MES_Order, MES_Sewing, MES_Hr, MES_Sync.
  2. Lấy code mới 
    cd D:\MES
git pull
  3. Tạo thư mục chạy, chép file cấu hình 
    mkdir D:\MES-run\shared
copy D:\MES\backend\.env D:\MES-run\shared\.env
  4. Chạy 
    node deploy\deploy.cjs --root D:\MES-run
    Khi hỏi Đã sao lưu 5 database chưa? thì gõ y rồi Enter. Chờ vài phút tới khi thấy dòng Đang chạy: ... là xong.
    Script tự dừng app pm2 cũ tên mes và tạo app mới. Nếu app cũ tên khác (xem bằng pm2 ls), thêm --replace <tên app cũ> vào cuối lệnh.
  5. Kiểm tra 
    pm2 ls
    Thấy app mes, cột status là online. Mở web, đăng nhập thử.
    Nếu trước đây máy chủ đã tự bật pm2 khi khởi động lại máy thì giữ nguyên, không cần làm gì thêm.
Máy chủ mới hoàn toàn (chưa có gì)?

Trước bước 1, làm thêm:

  • Cài Node.js 22, Git, SQL Server (5 database và tài khoản SQL đã có).
  • Cài pm2: npm install -g pm2@7.0.4
  • Lấy mã nguồn: git clone <địa chỉ repo> D:\MES
  • Ở bước 3: không có file để chép, tạo D:\MES-run\shared\.env theo mẫu D:\MES\backend\.env.example (mật khẩu DB, JWT_SECRET...).

2. Có code mới (git pull về để chạy)

Làm mỗi lần có bản mới. Không cần dừng pm2, không cần npm ci, không cần build tay.

  1. Chạy một lệnh 
    cd D:\MES
node deploy\deploy.cjs --root D:\MES-run
    Script tự git pull, cài gói, build. Trong lúc đó web vẫn chạy bình thường.
  2. Nếu script hỏi "Đã sao lưu 5 database chưa?" Nghĩa là bản mới có thay đổi database. Sao lưu 5 database rồi gõ y, Enter.
    Lúc này web sẽ dừng khoảng 20–60 giây. Nên làm ngoài giờ.
    Nếu người viết code báo bản này chỉ thêm bảng, thêm cột thì thêm --online-migrate vào cuối lệnh ở bước 1: web không dừng.
    Không hỏi gì thì web không dừng chút nào.
  3. Xong Thấy dòng Đang chạy: ... là xong. Báo người dùng bấm F5.

Khi có vấn đề

Script báo ... đã quay về ...Bản mới bị lỗi, script đã tự chạy lại bản cũ. Web vẫn dùng được. Gửi file D:\MES-run\logs\mes-error.log cho người viết code.
Muốn quay lại bản trước
node deploy\deploy.cjs --root D:\MES-run --rollback
Xem đang chạy bản nào
node deploy\deploy.cjs --root D:\MES-run --status
Sửa cấu hình (mật khẩu DB, cổng...)Sửa file D:\MES-run\shared\.env, rồi chạy:
node deploy\deploy.cjs --root D:\MES-run --sync-env
Script báo Cảnh báo: ... cho Everyone, Authenticated Users, Users truy cậpThư mục D:\MES-run (chứa mật khẩu DB) đang mở cho mọi người đọc. Mở PowerShell bằng quyền quản trị, chạy lệnh icacls mà script in ra.
Thông báo khácĐọc dòng Lỗi: script in ra, thường có ghi cách xử lý. Chi tiết: tài liệu 11-van-hanh.md, mục Cập nhật bản mới lên máy chủ.

Chạy các lệnh bằng đúng tài khoản Windows đang chạy pm2. Không sửa file trong D:\MES-run\current, không xóa file .mes-deploy.
