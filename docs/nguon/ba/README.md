# Tài liệu đầu vào của BA

Thư mục chứa tài liệu gốc do BA cung cấp (mô tả giao diện, đặc tả nghiệp vụ, file mẫu Excel, ảnh mẫu). Đây là tài liệu đầu vào: giữ nguyên bản BA gửi, không sửa; nội dung đã làm thành code thì mô tả ở tài liệu module trong [docs/update_docs](../../update_docs/README.md).

- Mẫu viết yêu cầu cho BA: [../yeu-cau/mau-mo-ta-yeu-cau.html](../yeu-cau/mau-mo-ta-yeu-cau.html).
- Không đưa dữ liệu thật (tên khách hàng, số PO, thông tin nhân viên) vào đây nếu file sẽ được commit; cần thì thay bằng dữ liệu giả.
- Chưa có file nào (19/10/2026). Các file ADR và file phase cũ từng dẫn tới (`BẢNG MÔ TẢ GIAO DIỆN MES - ĐƠN HÀNG.docx`, `Copy of TNG TT CHUAN BI SX.xls`, `Kết nối Bravo VietSun (2).xlsx`…) không còn trong repo.
